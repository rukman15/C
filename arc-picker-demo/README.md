# Arc Picker demo

A small Vite + React + Tailwind CSS v4 page for trying beUI's Arc Picker.

- `src/components/motion/arc-picker.tsx` and `src/lib/*` are copied unchanged from `../beui`
  (MIT, see `../beui/LICENSE`).
- `src/index.css` holds the few beUI theme tokens the picker uses, for light and dark.
- `src/App.tsx` is the demo: switch the curve side (top, bottom, left, right) and the theme.

```
npm install
npm run dev
```
